# SecondBrain – Daten-Repo

Dieses Repo speichert die Daten deiner SecondBrain-App (Eingangskorb, Einträge, Ablagen, Einstellungen) als JSON-Dateien.

- **Privat lassen:** Hier liegen persönliche Notizen und Aufgaben. Das Repo darf nicht öffentlich sein.
- Die App liest und schreibt die Dateien selbst; bitte nicht von Hand ändern.
- Der Workflow unter `.github/workflows/` startet auf Knopfdruck das automatische Sortieren (nur mit eingerichteten Secrets).

Einrichtung und Anleitung für Tester: https://github.com/Mc-Babex/secondbrain/blob/stable/docs/TESTER-ANLEITUNG.md
